# Montážny návod (`sk.montazny.navod`)

## Commands

| Command | Popis |
|---|---|
| `MONTAZ_ISOLATE_SELECTED` | Izoluje označené objekty |
| `MONTAZ_HIDE_SELECTED` | Skryje označené objekty |
| `MONTAZ_SHOW_ALL` | Zobrazí všetko |
| `MONTAZ_SELECTION_INFO` | Vypíše počet označených objektov |

Plugin zatiaľ nezapisuje vlastné XDATA.
